# GlossGenius-inspired SilkGlow rebuild

## What will change
- Recompose the homepage to mirror the reference’s visual rhythm: transparent top navigation, cinematic full-screen opening, large lower-left message, pill-shaped actions, and floating utility control.
- Replace the vertical treatment rows with an interactive seven-slide treatment showcase featuring a counter, large image, layered detail panel, arrow controls, drag/swipe support, and smooth transitions.
- Carry the same bold, spacious style through results, specialist, reviews, booking, location, and footer sections while retaining SilkGlow’s existing business content.
- Add scroll reveals, image movement, marquee motion, slide transitions, button micro-interactions, and reduced-motion fallbacks.
- Keep the site as one continuous, mobile-friendly booking journey and verify it on desktop and phone sizes.

## Technical details
- Reuse the project’s existing treatment photography and UI controls.
- Keep all visual values in semantic theme tokens and all interactions accessible by keyboard.
- Preserve current metadata, phone, address, hours, and external booking behavior.
